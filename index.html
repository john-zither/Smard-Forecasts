SMARD demand scoreboard

Every day at 12:00 (Berlin), a model forecasts tomorrow's grid load for Germany and its four transmission regions without using SMARD's forecast. Each forecast is committed to GitHub before the day happens, then scored against SMARD's own day-ahead forecast.
